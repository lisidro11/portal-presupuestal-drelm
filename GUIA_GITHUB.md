# Publicación en GitHub

1. Descomprime `Portal_DRELM_GitHub_Codigo.zip`.
2. Crea un repositorio **privado** en github.com.
3. Sube `app.py`, `requirements.txt`, `.streamlit/config.toml`, `.gitignore`, README y los scripts BAT. **No subas la carpeta privada**.
4. En share.streamlit.io, crea una aplicación con ese repositorio y `app.py`.
5. Al ingresar como administrador, sube el Excel enriquecido y luego carga la matriz validada para crear cuentas.

**No distribuir cuentas reales en Streamlit Community Cloud:** el SQLite local puede perderse con reinicios. Para usuarios institucionales se requiere almacenamiento persistente y endurecimiento de seguridad.
